# Relay

### Webhook infrastructure without the headache.

Receive, inspect, route, retry, and monitor webhooks from one powerful desktop app.

[Download for macOS](../../releases/latest) · [Report a Bug](../../issues) · [Request a Feature](../../issues)

</div>

---

Relay is a cloud-powered webhook infrastructure platform built around a fast desktop experience.

Your infrastructure runs in the cloud. Relay gives you the control center.

## Features

- Live webhook events and delivery status
- Automatic retries and event replay
- Payload, headers, responses, and metadata inspection
- Endpoint management
- Delivery logs and latency monitoring
- Failure detection
- Local development forwarding
- MCP connections
- Relay Cloud sync

## How it works

```text
Your App
    │
    ▼
Relay Cloud
    │
    ├── Receive
    ├── Queue
    ├── Route
    ├── Retry
    ├── Monitor
    │
    ▼
Your Endpoint
```

The Relay desktop app is the control center for the cloud delivery pipeline.

## Install on macOS

1. Open [Releases](../../releases/latest)
2. Download the latest `Relay.dmg`
3. Open the DMG
4. Drag Relay into Applications
5. Launch Relay and sign in

> Relay is currently distributed directly through GitHub Releases.
