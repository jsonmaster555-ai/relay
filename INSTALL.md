# Installing Relay on macOS

Relay is distributed as a macOS DMG through GitHub Releases.

## Install

1. Go to the latest GitHub Release.
2. Download `Relay.dmg`.
3. Open the downloaded disk image.
4. Drag Relay into the Applications folder.
5. Open Relay from Applications.
6. Sign in to connect the desktop client to Relay Cloud.

## Updates

New builds will be published through GitHub Releases.

## Security

Only install Relay builds published from this repository.
